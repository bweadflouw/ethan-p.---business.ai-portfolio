A founder spent 45 minutes every morning sorting 50+ email replies. High-value leads kept getting buried under auto-replies and "not interested" messages.

What I built

  1. Automation pulls the full thread and looks up the sender
  2. Claude Code classifies: routine, needs judgment, or high-value
  3. Routine sends auto. Judgment calls hit Slack. Hot leads go direct.
  4. Every interaction updates CRM + queues SMS follow-up
Key insight: Most people automate all email or none. The value is in the split.

An e-commerce team processing hundreds of orders daily had no early warning system. Problems surfaced when customers complained.

What I built

  1. Order data pulls in daily from the platform
  2. Claude Code analyzes against rolling baselines
  3. Sorted by severity: Normal = digest. Warning = Slack. Critical = ops lead.
  4. Dashboard with trends and recommended actions
Key insight: Catching problems isn't hard. The value is context. Is a refund spike seasonal or something to act on?
